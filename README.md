# UAVX Groundstation

Ground Control Station for UAVX flight controllers.

## Kits

| Platform | Build |
|----------|-------|
| Linux | `cd linux && bash build.sh` |
| macOS | `cd macos && bash build.sh` |
| Windows | Double-click `build.bat` |

All kits create a standalone executable via PyInstaller with a local venv.
